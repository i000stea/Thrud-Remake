- `Player/PlayerControl.cs(.Designer)` → `Battle_PlayerControl.cs(.Designer)`：改名后只做"场景装配 + 系统生命周期驱动 + 桥接同步"，ESC 仅派发 `BattlePauseToggleRequestedEvent`，**不再持有任何 UI prefab 字段**。
- 自建 `BattleUiRoot` / 旧 `BattleLevelResultView` / `BattlePauseMenuView` 全部删除（场景无引用）。
- `UI/BattleLevelResultPanel(.Designer).cs`（+ `BattleLevelResultPanelData` 标题注入）、`UI/BattlePauseMenuPanel(.Designer).cs`：CodeGenKit partial 标准 UIPanel，按钮走 `UIKit.ClosePanel` + `BattleLevelFlow.Restart` / 恢复事件。
