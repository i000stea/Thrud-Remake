# Login 模块设计

## 模块定位

`Login` 是单机阶段的进入页与玩家资料入口。当前阶段不做真实账号系统，但必须把未来账号、云存档、联机鉴权的接口预留好。

## 职责边界

负责：

- 开始游戏 / 继续游戏 / 设置 / 退出
- 玩家昵称、头像、存档槽位入口
- 本地资料选择与加载
- 未来账号接口预留

不负责：

- 启动初始化
- 主城导航
- 存档读写细节
- 热更逻辑

## 首版功能要点

- 显示当前本地可用存档槽位
- 支持“新游戏 / 继续游戏 / 切换存档槽”
- 支持昵称、头像等轻量资料页
- 提供未来账号接口占位，不接真实服务

## 建议页面结构

- 开始游戏
- 继续游戏
- 存档槽位列表
- 资料页
- 设置入口

## 数据所有权

- 玩家当前显示资料来自 `Profile`
- 存档槽位列表来自 `Save`
- 版本与构建信息可由 `Boot` 注入显示

## 关键接口

- `ILoginFlowService`
- `IAccountGateway`（占位）
- `ICloudSaveGateway`（占位）

## 状态流

```text
Boot -> Login
Login
  -> 选择存档槽
  -> 加载 Profile
  -> 进入 MainCity
```

## 依赖关系

- 依赖：`Profile`、`Save`
- 被依赖：`Boot`

## 首版验收

- 至少支持一个新档创建与已有档继续
- 切换存档槽后，进入主城的玩家状态正确
- 未来账号接口存在，但关闭时不影响单机流程

## 后续扩展

- 真实账号绑定
- 云存档同步
- 联机鉴权与好友入口
