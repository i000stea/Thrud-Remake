# Task 模块设计

## 模块定位

`Task` 是目标与奖励推进模块，负责把“新手引导”“主线目标”“每日任务”“成就/收集”统一到一套任务状态系统里。它不直接发奖励，只发奖励申请给 `Economy` / `Bag`。

## 职责边界

负责：

- 新手引导任务
- 主线进度任务
- 每日任务
- 成就 / 收集任务

不负责：

- 主城导航本身
- 奖励入库实现
- 章节剧情演出

## 首版功能要点

- 围绕首次编队、首次战斗、首次升级建立新手引导任务链
- 主线按关卡章节推进
- 每日任务提供轻量重复目标
- 成就记录长期收集行为

## 统一任务结构

- `TaskId`
- `TaskType`
- `ConditionSet`
- `Progress`
- `State`
- `RewardBundle`

## 状态流

```text
Locked -> Active -> Completed -> Claimed
```

## 依赖关系

- 依赖：`Profile`、`Config`、`Economy`、`Bag`
- 被依赖：`MainCity`

## 首版验收

- 战斗、养成、抽卡行为都能推动任务进度
- 任务奖励领取统一走规则与入库流程
- 引导任务不会把业务逻辑写死在主城或战斗模块里

## 后续扩展

- 周常任务
- 活动任务
- 更复杂的多条件成就链
