# Profile 模块设计

## 模块定位

`Profile` 管玩家当前状态，是“玩家是谁、现在发展到哪一步”的模块。它不处理存档介质，但向 `Save` 提供持久化数据。

## 职责边界

负责：

- 玩家昵称、头像、等级
- 章节与关卡进度
- 首通状态
- 基础偏好设置
- 当前主要成长状态引用

不负责：

- 文件读写
- 背包库存运算
- 经济规则

## 首版功能要点

- 维护玩家基础资料
- 维护关卡通关与评价记录
- 维护解锁状态、首次完成状态
- 维护偏好设置与当前选择状态

## 与 Save 的分工

- `Save`：怎么存、怎么读、怎么迁移
- `Profile`：玩家状态是什么、结构怎么组织

## 依赖关系

- 依赖：`Save`
- 被依赖：`Login`、`MainCity`、`Formation`、`Grow`、`Task`、`Gacha`

## 首版验收

- 不同存档槽位对应不同 `Profile`
- 主城显示的资料与真实状态一致
- 章节进度与任务推进可关联

## 后续扩展

- 更复杂的成就统计
- 社交资料与名片页
- 联机身份占位
