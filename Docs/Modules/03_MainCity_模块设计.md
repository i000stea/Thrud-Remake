# MainCity 模块设计

## 模块定位

`MainCity` 是 2D 功能页中枢，负责汇总状态、提供导航与展示红点，但不直接承接具体业务逻辑。它应该像“总入口”，而不是“总控制器”。

## 职责边界

负责：

- 功能导航
- 资源概览
- 通知红点
- 运营入口占位

不负责：

- 具体养成计算
- 抽卡结算
- 任务结算
- 战斗入场数据组装

## 首版功能要点

- 展示玩家等级、主要货币、基础资料
- 导航到 `Formation`、`Battle`、`Grow`、`Bag`、`Task`、`Gacha`
- 红点汇总：可领取、可升级、可解锁、可完成
- 运营入口占位：邮件、活动、公告、商店

## 页面组成建议

- 顶栏：头像、昵称、等级、货币
- 中央：主视觉或当前活动占位
- 底部/侧栏：功能导航按钮
- 浮层：公告、邮件、活动占位弹窗

## 数据来源

- 玩家等级与昵称：`Profile`
- 货币与资源总览：`Economy`
- 红点状态：各模块通过统一红点协议上报

## 关键接口

- `IMainCityNavigationService`
- `IRedDotProvider`
- `IEntryVisibilityPolicy`

## 依赖关系

- 依赖：`Profile`、`Economy`、`Task`、`Bag`、`Grow`、`Formation`、`Gacha`
- 被依赖：`Login`

## 首版验收

- 所有业务模块都能从主城进入
- 红点刷新不依赖手动重开界面
- 主城只转发导航，不直接处理业务结算

## 后续扩展
