# TelemetryLog 模块设计

## 模块定位

`TelemetryLog` 是基础设施模块，负责统一日志、埋点、异常记录与问题导出。它不参与业务裁决，但服务所有业务模块。

## 职责边界

负责：

- 分级日志
- 埋点协议
- 异常记录
- 会话追踪
- 问题导出

不负责：

- 业务规则决定
- 配置表解释
- 资源更新

## 首版功能要点

- `Debug / Info / Warn / Error / Fatal` 分级日志
- 会话级埋点文件
- 战斗、抽卡、成长、货币等关键事件记录
- 崩溃前日志 flush
- 开发期问题导出入口

## 关键事件域

- `battle:*`
- `gacha:*`
- `grow:*`
- `currency:*`
- `task:*`
- `load:*`
- `error`

## 依赖关系

- 依赖：无
- 被依赖：`Boot`、`Battle`、`Grow`、`Bag`、`Task`、`Gacha`、`Save`、`Economy`、`HotUpdate`

## 首版验收

- 能按会话追踪问题
- 关键错误不会丢日志
- 货币与战斗关键行为都可回放分析

## 后续扩展

- 真正的远端上报
- 开发者诊断面板
- 自动汇总回归测试报告
