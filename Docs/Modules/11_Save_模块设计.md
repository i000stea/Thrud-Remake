# Save 模块设计

## 模块定位

`Save` 只负责读写、版本迁移、备份恢复与存档槽位管理。它不解释业务状态含义，也不决定哪些状态应当如何展示。

## 职责边界

负责：

- 本地存档读写
- 版本迁移
- 多存档槽位
- 备份恢复
- 云存档接口占位

不负责：

- 玩家资料逻辑
- 货币规则
- 背包运算

## 首版功能要点

- 支持多存档槽位
- 支持新建、读取、覆盖、删除、切换
- 支持存档版本升级迁移
- 支持异常恢复与备份
- 预留云存档接口，不接真实服务

## 建议结构

- `SaveRepository`
- `SaveMigrationRunner`
- `SaveSlotService`
- `CloudSaveGateway`（占位）

## 依赖关系

- 依赖：`TelemetryLog`
- 被依赖：`Boot`、`Login`、`Profile`

## 首版验收

- 旧版本存档可迁移
- 切换存档槽不会串档
- 存档损坏时有恢复提示与备份策略

## 后续扩展

- 云端冲突合并
- 自动备份策略
- 更细粒度的数据分块保存
