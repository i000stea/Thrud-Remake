# 核心玩法设计（空战战斗）

> 本文档定义重制版的核心战斗体验。参照原版《斯露德》（3D 空战、四角色切换、锁定射击、元素机制）并结合本工程现有实现。首版范围遵循决策 D05-D07、D10：全 3D 空域、半自动锁定、元素首版为克制 + 独立状态、内容精而少。

## 核心战斗循环

```
编队(≤4人) → 进战斗 → 空域战斗 → 目标达成/团灭 → 结算(评价/掉落/用时)
                    ↑_______________________|
                       变强后重刷更高评价
```

循环的驱动点：每场战斗结束给成长材料，成长提升编队战力，战力推动挑战更高评价与更难关卡（见外围系统文档的三线养成）。首版用 3-5 个关卡验证"战斗 → 变强 → 再战斗"的正反馈成立。

## 飞行与移动（D05：全 3D 空域）

- 移动：水平面 WASD/摇杆 + 上下轴（原版最终形态的"上下飞行"），世界空间 6 向自由移动
- 加速/冲刺：现有 `BattleMovementSystem` 的"翻滚 → 冲刺"连段保留；翻滚提供短暂无敌帧（建议 0.25s，可调），冲刺提供速度与 FOV 拉升（现有 `SprintFov` 逻辑）
- 相机：Cinemachine 第三人称跟随 + 鼠标/右摇杆旋转；相机不跟随角色翻滚，只做缓动偏移
- 速度感：FOV 随速度插值（已有）、镜头微震（受击/开火时可选）
- 边界：关卡用空气墙或场景体积约束活动范围，首版不追求无限地图

手感参数表（首版建议值，全部进配置表，可在游戏中热更调整）：

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 基础移动力 | 按角色差异化（先锋高机动/学者中速） | 影响走位手感 |
| 冲刺倍率 | 2.2x 基础速度 | 原版冲刺感强 |
| 翻滚无敌帧 | 0.25s | 攻防节奏的支点 |
| FOV 冲刺拉升 | 基础 60° → 冲刺 70° | 已有实现 |
| 鼠标灵敏度 | 0.1 rad/s（可调） | 已有实现 |

## 锁定与瞄准（D06：默认半自动，待最终确认）

现有 `BattleAimSystem` 已是"屏幕距离 + 世界距离"综合判定的锁敌雏形，首版默认设计在其上增强：

- 准星接近敌人一定屏幕距离（建议 200px，可调）时吸附，锁定后准星插值追踪（已有 `LockEnemySpeed` 动态倍率逻辑）
- 锁定目标后，弹道向锁定点做小幅修正（修正强度按武器类型区分：散射弱修正、狙击强修正）
- 切换目标：PC `Tab` / 移动端右摇杆轻推；无目标时自动选择最近目标
- 解锁条件：目标死亡、超出锁定距离、玩家主动取消

锁定手感备选方案（评审时二选一，默认 A）：

| 方案 | 描述 | 优点 | 代价 |
|------|------|------|------|
| A 半自动（默认） | 吸附 + 可切换 + 弹道修正 | 还原原版，双端友好 | 命中判定与弹道修正需调参 |
| B 全自动 | 自动锁定最近目标，准星自动追踪 | 实现最简 | 操控感弱 |
| C 手动瞄准 | 无锁定修正 | 硬核枪法 | 移动端触控体验差，不推荐 |

## 武器系统（4 类 16 子类）

原版武器四类已在本工程完整对应：旧版 `WepMode_*` 与新版 `BattleWeaponMode_*` 一一映射。重建后统一到新架构（`BattleWeaponModeBase` 已有）。

| 大类 | 基础手感 | 子类数 | 代表子类 | 弹道特征 |
|------|----------|--------|----------|----------|
| 突击型 | 中速连发、弹匣大、散布随射击增大 | 5 | 精确/能量/速射/专注/强攻 | 直线弹道、弹道修正适中 |
| 重装型 | 慢速高伤、追踪或直射飞弹、换弹慢 | 4 | 追踪/强力/轻质/多联装 | 追踪型可锁定修正、直射型高抛 |
| 散射型 | 低速爆发、扇形弹幕、近距伤害高 | 2 | 重击/精确霰弹 | 多发扇形、衰减明显 |
| 狙击型 | 单发高伤、需蓄力或连发节奏、弹匣小 | 4 | 穿透/连发/迅捷/充能 | 直线、穿透或充能机制 |

规则（原版特色，全部保留）：

- 弹匣机制：射击消耗弹匣，**切换队员补满弹药**——切人不仅是换输出，也是换弹策略
- 换弹：空仓后自动/手动换弹，换弹期间可移动不可攻击
- 武器与角色绑定：每个角色固定武器类型，武器可升级（见外围系统）

## 元素机制（D07：首版克制 + 独立状态，架构预留附着/相变）

原版元素为雷/冰/火/风。首版实现：

**克制关系**（伤害修正，可调系数，建议 1.25x）：

```
雷 ──克制──► 冰
 ▲            │
 │            ▼
风 ◄──克制── 火
```

**独立状态效果**（命中积累状态值，触发后按持续时间生效）：

| 元素 | 状态 | 效果 |
|------|------|------|
| 冰 | 寒冷 | 减速 30%（可叠加至 2 层） |
| 火 | 灼烧 | 每秒 DoT（基于攻击力百分比） |
| 雷 | 麻痹 | 短时定身 + 连锁溅射（相邻敌人） |
| 风 | 牵引 | 小范围聚怪 + 易伤 10% |

**架构预留（不进首版内容）**：定义 `IElementAspect`（附着数据）与 `IElementReaction`（相变规则）接口，元素状态模块按接口扩展。首版内容相当于"每个元素只有一种状态效果"的最简相变集；后续要加入"冰 + 雷 = 超导"类连锁反应时，只需新增 Reaction 规则，不重构伤害管线。

## 技能与角色切换

- 序曲（小技能）：短 CD（5-10s），角色差异化（治疗/护盾/范围输出/聚怪），占"元素战术"位
- 极奏（大招）：共享/个人能量条，攒能方式为命中与击杀，高倍率 + 大范围表现
- 蓄力攻击：长按开火，狙击型核心输出手段（已有 `SniperCharged` 子类）
- 切人：即时切换（不打断移动），切换时释放一次轻量"切人技"（原版为"武器过载期间切人放技能"，首版简化为切人自带一次短时增伤或清弹幕），冷却由队伍共享（建议 1.5s）

## 敌人与关卡（D10：精而少）

敌人首版清单（灰盒）:

| 敌人 | 行为 | 弱点 | 定位 |
|------|------|------|------|
| 追猎者（近战） | 高速逼近 + 爪击 | 风/雷 | 数量型小怪 |
| 炮击者（远程） | 中距离弹幕，弹速中 | 火 | 逼迫走位 |
| 装甲者（重甲） | 慢速高防，正面免伤 | 冰（减速后绕后） | 验证切人与元素 |
| 自爆者 | 冲脸自爆，大范围 | 雷（提前触发） | 压力波次 |
| 精英：督军 | 以上某种的强化 + 召唤小怪 | 特定元素克制 | 节奏分段点 |
| Boss：异生体首领 | 多阶段（弹幕 / 召唤 / 狂暴），带护盾条 | 各阶段不同 | 关卡高潮 |

关卡模式（3 模式 × 2 关 + 1 Boss 关 = 首版 5 关左右）：

- 清剿：全灭敌人，含 1 次精英遭遇
- 护送：保护目标（NPC 或运输体）走完全程，目标血量计入评价
- 防守：坚守据点抗 3-5 波，波间可拾取补给
- Boss 关：多阶段战斗，带教学性质（每阶段演示一种机制）

敌人 AI 用轻量状态机（巡逻/追击/攻击/受击/死亡），不引入行为树插件，控制在 `EnemyController` + 配置表参数内。单屏活跃敌人上限建议 20（性能约束见性能文档）。

## 战斗结算

- 评价：S / A / B / C，由通关时间、承伤、存活人数、护送目标血量综合判定（权重可配）
- 掉落：经验材料、货币、武器强化材料、低概率碎片；掉率进配置表
- 结算界面：评价动画（灰盒阶段为简单表现）+ 掉落列表 + 一键再来 / 返回
- 埋点：每场战斗写入完整数据（见性能与埋点文档）

## 手感验收标准（灰盒阶段即可量化验证）

| 指标 | 目标值 | 验证方式 |
|------|--------|----------|
| 开火到命中反馈延迟 | ≤ 100ms | 慢放检查命中判定帧 |
| 锁定吸附响应 | ≤ 200ms（目标进入吸附区） | 录制回放 |
| 冲刺/翻滚手感 | 连段无输入丢失 | 手感测试场景连续操作 |
| 切人响应 | 指令到角色切换 ≤ 1 帧 | 帧调试 |
| 单屏战斗帧率 | PC 60fps / 中端安卓 45fps+ | Profile 采样 |
| 一场普通关时长 | 3-5 分钟 | 试玩统计 |

## 与原版及现有代码的关系

- 现有 `BattleArchitecture` 的 7 个 System（角色/输入/移动/表现/相机/锁敌/武器）全部保留并纳入新架构，这是重制战斗的骨架
- 旧 `Before/03Battle` 的模块化玩家控制（`P_*` 组件）、武器模板（`WepMode_*`）、敌人控制（`EnemyControl`）作为算法参考，不直接迁移代码
- 原版的教训被写进验收标准：**核心手感以量化指标锁死，不再"听取反馈推翻重做"**；后续玩家/自我反馈只做参数微调，不做机制推倒
