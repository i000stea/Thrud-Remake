## 2. 涉及构成环节（按代码路径）

### 2.1 玩家 → 敌人（命中结算）
- 子弹：`Assets/02_Scripts/03_Battle/Weapon/BattleBullet.cs`（`OnTriggerEnter` → `ApplyElementalDamage(Damage, Element)`）；
- 武器源伤害写入：`Assets/02_Scripts/03_Battle/Weapon/BattleWeaponRuntime.cs`（`ApplyBulletDamage`，新旧两套子弹兼容）；
- 敌人受击结算：`Assets/02_Scripts/03_Battle/Enemy/BattleEnemyEntity.cs`
  - `ApplyElementalDamage`：原始伤害 × 克制倍率(`BattleElementBalance.GetMultiplier`) × 风易伤(`mElementState.IncomingMultiplier`) → `ApplyDamageInternal`；
  - `TakeDirectDamage`：DoT/电溅射等直接伤害（不递归元素）；
  - `ApplyDamageInternal`：扣血 + 飘字（白/元素色/克制金放大 `counterBig`）。

### 2.2 元素联动（T2.3/T2.4）
- `Assets/02_Scripts/03_Battle/Element/BattleElementBalance.cs`：克制倍率/电链溅射比例(0.5)/火dot/风易伤系数等**数值常量**；
- `Assets/02_Scripts/03_Battle/Element/ElementStateEffect.cs`：火 DoT(`FireDotDamage`)、电溅射传导、风易伤叠乘等。

### 2.3 敌人 → 玩家
- `Assets/02_Scripts/03_Battle/Core/BattleHealthSystem.cs`：成员级血量受击结算（扣当前出战角色）、阵亡/自动切人、`BattlePlayerDamagedEvent`；
- 敌人伤害来源：`BattleEnemyEntity`（弹幕/爆炸）、`EnemyBehaviour_Missile` 爆炸半径结算。

### 2.4 数值/展示来源
- 成员血量/属性：`BattleRoleRuntimeData`（MaxHp 取自角色 SO `RoleItem_Data`）、`BattleTeamRuntimeBuilder` 编队实体化；
- 飘字/颜色放大：`BattleEnvironmentEffectController`；
- HUD：`BattleTeamHudView`（队伍血条）等。

## 3. 待查清单（Debug 时逐项核对）

- [ ] 复现步骤与涉及对象（哪一方扣血异常 / 哪种武器/元素 / 是否切人后）；
- [ ] 飘字数值 vs 实际扣血 vs 模型/血条 三者一致？（怀疑点常见：仅显示问题或仅结算问题）
- [ ] 克制倍率/风易伤叠乘是否符合预期（乘法顺序、是否重复计算）；
- [ ] 元素状态伤害（火dot/电溅射 50%/风易伤）是否被重复计入飘字或结算；
- [ ] 子弹伤害是否被新旧两套子弹脚本**双重结算**（`BattleWeaponRuntime` 兼容层风险点）；
- [ ] 玩家侧：敌人弹幕/爆炸伤害是否被错误成员/错误时机承受；成员切人与 DoT 生效对象的归属。
