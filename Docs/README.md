## 2. 分类口径

按**文档用途（类型）**划分：

- **总览**：项目级定位与决策，一切文档的根。
- **里程碑与执行**：长期规划（M0–M3）、当前里程碑施工图（M1 任务卡）、单期专项计划（Android Demo）。
- **系统与玩法设计**：横切多个模块的方案——架构、热更、玩法、外围系统、性能与埋点。模块级拆分单独放入「模块设计」。
- **专项设计与重构**：围绕单个场景/任务卡的设计（ConfigScene 常驻架构、Battle_Arena 薄场景化、预编队面板重构）。
- **模块设计**：把目标架构按 Boot/Login/MainCity/Formation/Battle/Grow/Bag/Task/Gacha/Config/Save/Profile/Economy/HotUpdate/TelemetryLog 拆成的模块文档（“目标结构”，多数为方案先行）。
- **开发日志**：按时间/会话记录的开发过程、验收、坑与交接。
- **问题存档**：问题/怀疑的留档与调试提醒（区别于正式设计）。
- **下一步行动**：汇总摘编各文档“下一步要做”的清单（保留可追溯来源）。
