# Config 模块设计

## 模块定位

`Config` 是表驱动配置模块，负责统一管理战斗数值、UI/表现配置、经济配置与校验工具。它要把“哪些东西进表、哪些东西禁止硬编码”写死。

## 职责边界

负责：

- 战斗数值表
- UI / 表现配置
- 经济配置
- 配置校验工具
- 热更加载后的配置生效

不负责：

- 存档持久化
- 业务状态解释
- 运行时日志

## 配置层次

- 战斗：角色、武器、敌人、关卡、掉落、元素
- UI：页面入口、红点规则、按钮显隐、演出开关
- 经济：价格、奖励、卡池规则、商店占位
- 校验：外键、概率和、缺表、热更加载一致性

## 核心原则

- 数值只在配置表里定义
- 配置是模块外显契约，不是随手存放常量的仓库
- 所有配置表都要可热更

## 关键接口

- `IConfigProvider`
- `IConfigValidator`
- `IHotReloadConfigApplier`

## 依赖关系

- 依赖：`HotUpdate`
- 被依赖：几乎全部业务模块

## 首版验收

- 所有战斗与经济核心数值都能查到配置来源
- 配置错误能在构建期或启动期被发现
- 热更后配置版本与代码版本能被记录

## 后续扩展

- 编辑器可视化表工具
- 策划友好的校验报告
- 多语言配置与本地化表
