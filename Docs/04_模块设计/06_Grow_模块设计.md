# Grow 模块设计

## 模块定位

`Grow` 是养成模块，负责角色、武器、符灵三条成长线以及角色详情展示。它负责“如何变强”，不负责“资源从哪来”与“是否允许消费”这类经济规则。

## 职责边界

负责：

- 角色升级 / 升星
- 武器强化 / 突破
- 符灵装配
- 角色详情展示

不负责：

- 物品库存扣减实现
- 货币价格定义
- 关卡奖励产出

## 首版功能要点

- 角色等级、经验、升星
- 武器强化、突破、等级上限控制
- 简化符灵槽位与装配
- 角色详情页：属性、技能、成长、展示页

## 建议内部拆分

- `HeroGrow`
- `WeaponGrow`
- `FafnirLoadout`
- `HeroDetailPresenter`

## 输入与输出

输入：

- 角色模板、武器模板、符灵模板配置
- 当前持有资源

输出：

- 成长后的角色/武器状态
- 消耗申请
- 埋点事件

## 依赖关系

- 依赖：`Profile`、`Config`、`Bag`、`Economy`、`TelemetryLog`
- 被依赖：`MainCity`、`Formation`

## 首版验收

- 升级与突破会先校验资源与条件
- 角色详情与真实成长状态一致
- 养成后能反映到编队和战斗入场属性

## 后续扩展

- 技能升级树
- 更复杂的符灵词条
- 成长推荐与一键强化
