### 2.2 T2.1 敌人体系重做（6913399）
- **需求变更背景**：昨日原 6 类敌人方案（近战爪击/正面免伤/召唤/精英/Boss 等）经今日多轮沟通废弃，新规格＝敌人**仅弹幕为主 + 固定姿态移动（不持续追踪玩家）+ 取消位置盾 + 生成按条件触发**。
- 新 4 类（`EnemyKind`：Patrol/GunTurret/Missile/Mine + 行为策略工厂）：
  - 巡弋者：生成点半径内游走、不追玩家、单发速射；
  - 站桩炮台：不动，直线/扇形弹幕参数化，重装变体＝高血慢速重弹；
  - 自爆·导弹：追踪玩家贴近小爆（击落无爆）；
  - 自爆·地雷：静置，感应玩家或被击杀大爆（打爆会波及）。
- 敌人 **prefab 化**（`Assets/04_Prefabs/Enemy/`：5 敌人 prefab + 材质资产）；编辑器菜单 Create / Add / Rebuild。
- 自爆范围可视化（用户反馈补充）：地雷常驻感应圈（RangeRing 子对象）+ 爆炸瞬间 `ShowBlastRing` 池化红圈。

### 2.3 T2.2 区域波次与条件生成器（0dba8a9）
- **需求（用户原型）**：一串 3D 目标点站点按序激活 → 玩家到达刷首批 → **在场击杀 ≥80% 刷次批** → 清场激活下一站 → **整场限时**。
- 初版（场景刷怪点 BattleSpawnPoint + Director 嵌套引用数组）因配置分散繁琐被否；
- **重构为 SO 单表**：`StageConfig_Demo.asset`（站点/批次/刷怪条目）+ `EnemyCatalog.asset`（字符串 id ↔ prefab 映射）＋ `EnemyIdAttribute/EnemyIdDrawer`（字符串字段 Inspector 下拉重绘，**热更增敌只需在目录加条目**）；
- `BattleStageDirector` 只持配置引用，运行时自动生成目标点（光柱+到达圈）与刷怪位置，场景零改动；删除 BattleSpawnPoint 旧结构。
- 修复：EditorGUI.Popup 无 `(Rect,GUIContent,int,string[])` 重载 → PrefixLabel + 无 label 重载。

### 2.4 T2.3 元素系统（编码完成，未验证）
- 表现方案沟通（用户）确认：敌人元素需可视化 → **EnemyEntity_UI 用 QFramework View 重构并在 UI 临时体现元素** + 身体着色 + 头顶状态字 + 飘字元素色/克制金字 + 状态仅作用于敌人。
- 已落地：
  - `Element/BattleElementBalance.cs`：克制环 Electric→Ice→Fire→Wind→Electric（1.25×）；冰/火/电/风数值集中；
  - `Element/ElementStateEffect.cs`：四状态并行叠加组件（冰减速、火 DoT、电麻痹+溅射、风易伤+一次性聚怪）；
  - `BattleEnemyEntity`：`Element` 属性（敌人元素）/状态染色（电>火>冰>风优先）/`ApplyElementalDamage`（克制+易伤）/`TakeDirectDamage`/`CurrentMoveSpeed`（冰减速）与电麻痹停摆；
  - 子弹携带角色元素（`BattleRuntimeBridge.ActiveElement` ← PlayerControl 当前角色）→ 命中施加元素；
  - 飘字控制器支持元素色与克制放大金/大字；
  - StageConfig 刷怪条目加「敌人元素」字段 + 资产版本号（低版本自动重建）→ 默认演示带元素敌人（站1 炮台=风、站2 炮台=冰/导弹=电、站3 重装=火）。
- 已知限制：狙击武器命中暂不结算元素（射线仅表现），元素验证用突击/散射武器。
