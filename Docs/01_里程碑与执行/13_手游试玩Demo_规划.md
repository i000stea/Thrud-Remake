## 1. 目标与验收(一句话)

## 3. 分阶段方案

### 3.0 T0 · Android 最小包冒烟(0.5\~1 天,先行)

目的:**最先打穿"出包 + UI 能加载"**,因为 UIKit 面板走 **ResKit AssetBundle**,手机端最大翻车点 = AB 未进包 → 面板空屏。

- [ ] 检查/搭建 Android 环境(SDK/NDK、Debug keystore、包名、IL2CPP + ARM64、目标 API、横屏)

- [ ] ResKit AB 全量构建流程跑通并入库验证

- [ ] 最小链路真机:登录 → 主菜单 → 选关 → 编队 → 进关出 rig(面板不空屏)

- 产出:一键构建脚本雏形 + 真机验收清单 v0

### 3.1 T1 · 手机按钮映射(1\~2 天,与 T3 并行)

- 输入改造位置:`BattleInputSystem`(采集点单点插入虚拟源),战斗系统零改动

- 布局(首版,实机微调):

  - 左下:**移动摇杆**(含冲刺长按可选)

  - 右下:**普攻(大键)+ E/Q 技能 + 切人(←/→ 循环)+ 暂停**

  - 中央区域(约屏中 40% 宽度):**单指拖拽 = 镜头旋转**,自动索敌跟随镜头/锁敌

- 自动索敌优先:开火朝当前锁敌/镜头方向(改动最小);中心拖拽会微调索敌与视角

- 真机小项待验证:中央拖拽区与移动/按钮热区重叠判定、多指互斥、安全区(刘海/全面屏)、按钮触感反馈

- 回归:Editor 键鼠全程不回归

### 3.2 T3 · 剿灭关卡/敌人/角色调整(1\~2 天,与 T1 并行)

- 复用 `level_01`(ArtSceneName=BattleGraybox),站点数=3(对应三段节奏)

- 数值基准(P7):玩家 MaxHp≈400(角色 SO 需把工作区 60/40 压测残留改回正式值并**一并提交**);伤害/武器 DPS 按"单波 \~15s 手感"反推

- 关卡节奏表(初版):

  - 站1 教学 ~~25s:杂兵 4~~6 只(无远程/少量弹幕),熟悉移动+普攻

  - 站2 主力 ~~45s:混编 8~~12 只(近战+远程弹幕),压力峰

  - 站3 收尾 ~~20s:高价值目标 2~~3 只 + 小股杂兵,Q 清屏可用武之地

- 编队保留完整流程;战斗切人默认 3 人队可满编出战

- 失败/全灭 → 可立即"再来一次";胜利 → 结算 → 一键重开/返回主菜单

### 3.3 T2 · 打包收口与外放(0.5\~1 天)

- Android 一键构建(Editor 菜单:命名/版本/keystore/AB 打包→出包) + 文档

- 真机回归清单:全链路可玩、按键无死角、面板不空屏、帧率/发热粗测、防误触退出、包体控制目标(<200MB)

- 分发:debug 签名 apk 直接外放(内测),正式签名后补

## 4. 风险与对策

| 风险                      | 影响      | 对策                             |
| ----------------------- | ------- | ------------------------------ |
| ResKit AB 未打/加载失败(面板空屏) | 阻断外放    | **T0 最先打穿**,构建脚本固定 AB 顺序与校验    |
| 触屏手感(视角拖拽/索敌)           | demo 观感 | 中央拖拽区热区参数化;实机 2\~3 轮微调;键鼠不回退   |
| 数值失衡(一击秒杀/打不动)          | 劝退      | P7 基准 + 数值表逐项代入;保留工作区未提交数值避免误混 |
| 真机性能(URP/弹幕池)           | 卡顿      | 对象池已就绪;真机粗测帧率;必要时降分辨率/粒子       |
| 首次 Android 环境           | 时间不确定   | 若 SDK 缺失先列安装清单,给半天 buffer      |

## 5. 开放待验证小项(不阻塞启动)

- 切人键首版用「←/→ 循环」,是否需要四槽直接选(外放后按反馈调)

- 中央拖拽区的具体屏幕占比与边缘热区

- 冲刺(Sprint)是否独立按键,或并入摇杆外圈快速推

- 是否需要"自动开火"开关(减少外放操作门槛,可作隐藏项)
