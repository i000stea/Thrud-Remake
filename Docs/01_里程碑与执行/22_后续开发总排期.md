## 0. 四条排序原则

| # | 原则 | 理由（一句话） |
|---|------|----------------|
| 1 | **先升引擎，再装热更** | HybridCLR 的 il2cpp 补丁与 Unity 版本强绑定；反序 = 同一套活干两遍（`16` §5B 已裁定）。 |
| 2 | **先钉基线，再动大件** | 当前有一批「编译通过、Play 未验」的改动（宿主瘦身五步 / Actor 分层 / 桥接层退役 / legacy 武器删除）。不验就升引擎，出问题分不清是重构的锅还是引擎的锅。 |
| 3 | **地基先行** | `Save / Profile / Bag / Economy` 是 Menu、关卡、抽卡、养成的**共同前置**。缺它每个页面都是空壳：抽到的角色无处放、升的级存不下、关卡进度无处记。 |
| 4 | **表现基建先于内容扩量** | 后续角色/武器/敌人一律走「接入管线」，不逐个手写代码。否则每加一个角色都要回头改一遍框架。 |
